# 구현 프롬프트 4단계

로드맵 9단계(P0~P8) 중 필수 8단계를 프롬프트 4개로 묶었다. 순서대로 Claude Code에 붙여 넣고, 각 단계가 끝나면 보고서를 확인한 뒤 다음으로 넘어간다.

| 프롬프트 | 포함 단계 | 끝나면 되는 것 | LLM 필요 |
|---|---|---|---|
| [01](01-foundation-case-validator.md) 기반·사건·검증기 | P0 P1 P2 | CI, museum-001 YAML, `case-validator check` | 아니요 |
| [02](02-game-engine-api.md) 게임 엔진·API | P3 (+P5·P6 골격) | API만으로 사건 클리어, 누설 테스트 | 아니요 (Mock) |
| [03](03-frontend.md) 프론트엔드 | P4 | 브라우저 완주, Playwright E2E | 아니요 (Mock) |
| [04](04-ai-and-evals.md) AI·평가 | P5 P6 P7 | 로컬 Qwen 자유 심문, 평가 리포트 | 예 (Ollama) |

- 모든 프롬프트는 [00-common.md](00-common.md)의 공통 규칙을 따른다.
- P8(사건 생성기)은 포함하지 않았다. 필요하면 5번째 프롬프트로 추가한다.
- 한 프롬프트의 작업량이 크다. 중간에 컨텍스트가 길어지면 "이어서 진행해"라고 입력하면 된다. 보고서의 실패 항목은 다음 프롬프트로 넘어가기 전에 해결한다.
